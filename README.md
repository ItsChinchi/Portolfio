# Portfolio

Personal portfolio website of Ahmed Saad — game developer (Unreal Engine 5 · Unity).

## Files
- `js/game.js` — Crystal Collector mini game, shown in the hero (does nothing until Play is pressed)
- `js/effects.js` — intro, custom cursor, hero particles (`ENABLE_CURSOR_TRAIL` switch at the top)
- Icons are an inline SVG sprite in `index.html` (no icon font to download)
